# TrabalhoFinal_PIPOCA-E-GUARANA
Neste repositório, eu, Nicole Roque, e minha dupla, Gabriela Harumi, desenvolveremos o trabalho final de Programação Orientada a Objetos, o "Pipoca e Guaraná". O projeto demonstra, de forma prática, o aprendizado do semestre, aplicando conceitos como coleções, parametrização de tipos, expressões lambda, streams e outros.
